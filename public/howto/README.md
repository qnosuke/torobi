# やり方の動画

ここに `<slug>.mp4` を置くと、その種目の「?」を開いたときに文字の上に表示されます。
ファイルが無い種目は文字だけになります（置いていない状態でも壊れません）。

## 仕様

| 項目 | 値 |
|---|---|
| 形式 | MP4 / H.264 / **yuv420p**（iOSで再生できない事故を避けるため必須） |
| 画面比 | **4:3**（推奨 640×480。表示は幅300px） |
| 長さ | **4秒ちょうど**＝1回分（2秒で下ろす／2秒で上げる） |
| ループ | **継ぎ目なし**。最初と最後のコマが同じ姿勢になること |
| fps | 24〜30 |
| 容量 | 1本 **300KB以下**（音声トラックなし） |
| 音声 | 無し（アプリ側でミュート再生します） |

## 絵の作り方

- 背景は **#16120e**（アプリと同じ色）。枠や影は付けない
- 人物は **#ff7a2f 系のシルエットか線画**。顔・服の描き込みは不要
- ダンベルを持つ種目は器具も描く。重さの表記は不要
- **文字・ロゴ・数字は入れない**（説明はアプリ側が出します）
- カメラは固定。ズームやアングルの切り替えをしない
- 1本につき1回分の動作だけ。速度を変えない
