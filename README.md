# torobi

トロビ 12週プログラムのタイマーWeb app。まずはタイマー機能のみ。

## 使い方

`index.html` をブラウザで開くだけ（ビルド不要・依存なし）。

```
open index.html
```

またはローカルサーバーで:

```
python3 -m http.server 8000
# → http://localhost:8000
```

## 機能

- **ストップウォッチ（1セット目）**: 1タップ開始・1タップ終了。限界が来たら止めるだけ
- **メトロノーム内蔵**: 2秒下ろす／2秒上げるのテンポで鳴る（下ろし始め＝低い音、上げ始め＝高い音）。第7週以降用の「4秒↓ 2秒↑」にも切替可
- **8割タイマー（2セット目以降）**: 1セット目の秒数の8割を自動計算し、カウントダウン＋終了アラーム
- **秒数→回数の自動換算**: 「58秒＝約14回」を常時表示（1回＝テンポ合計秒）
- **画面スリープ防止**: 計測中はWake Lockで画面を維持（対応ブラウザのみ）

スマホでの利用を想定したモバイルファーストUI。
