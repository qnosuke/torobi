# TOROBI 🔥

**強火にしない。**

ネオプレンダンベル2つと自重だけで、12週。そのためのメソッドとタイマーです。

- **メソッド** → [METHOD.md](METHOD.md)
- **アプリ** → https://qnosuke.github.io/torobi/

## アプリについて

タイマーと体組成の読み取りが一本になったPWAです。iPhoneのSafariで開き、共有メニューから「ホーム画面に追加」すると全画面で起動し、オフラインでも動きます。

```sh
npm install
npm run dev      # 開発サーバー
npm test         # ユニットテスト
npm run build    # 本番ビルド（GitHub Pages用 base=/torobi/）
python3 scripts/gen-icons.py  # アイコン再生成
```

### できること

- **今日の6種目を自動で選ぶ** — 週（第1〜12週）から段階を判定し、具体的な種目名とやり方を表示。肩の日／腕の日は前回の逆を自動選択
- **ウォームアップのガイド** — 3分・4ステップを音で切り替え
- **1タップ計測** — 1セット目はストップウォッチ、2セット目以降は基準値の8割を自動カウントダウン
- **メトロノーム内蔵** — 下ろし始めが低い音、上げ始めが高い音。テンポは週と種目から自動（単関節は第7週から4秒下ろし）
- **左右別の基準値** — 片側種目は左→右で1セット。限界値も目標も側ごとに計算
- **前回比** — 1セット目の前に前回の秒数、終了時に差分を表示
- **体組成計の読み取り** — オムロン カラダスキャン KRD-203 の液晶をカメラで読み取り、7項目を自動入力（[krd-scan](https://github.com/qnosuke/krd-scan) の認識エンジンを取り込み）
- **記録** — 端末に自動保存。テキスト（メソッドの記録形式）とCSVで書き出し

計測中は画面を見ないで済むよう、音と振動で完結するようにしてあります。

### 技術メモ

- iOSの消音スイッチ対策として、Audio Session APIと無音ループでメディア再生セッションを維持
- 計測中はWake Lockで画面スリープを防止
- 記録は `localStorage`（端末内のみ。節目でCSVを書き出して保存推奨）
- カメラ映像は端末内で処理し、どこにも送信しません
- 7セグメント認識エンジンは実機動画から作ったフィクスチャでテスト済み（`npm test`）
- `main` へのpushでテスト→ビルド→GitHub Pagesへ自動デプロイ
